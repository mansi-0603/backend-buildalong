# 01 - Introduction

My first Express server.

## What I learned
- What a server is, and how to create one with `express()`
- Handling `GET` requests with `app.get()`
- Starting the server with `app.listen(3000)`

## Routes
| Method | Route | Response |
|---|---|---|
| GET | `/` | Hello Server ! |
| GET | `/about` | About page ! |
| GET | `/contact` | Contact page ! |

## Run
```bash
npm install express
node server.js
```
Open `http://localhost:3000`.
