# Backend BuildAlong

My backend learning journey with Node.js, Express, MongoDB and JWT authentication. Each folder is one stage, built while following a tutorial and practicing on my own.

## Folders

| Folder | What it covers |
|---|---|
| `01-introduction` | Node.js basics and the first Express server |
| `02-express-basics` | Routing and request/response basics |
| `03-notes-creation` | A notes API with CRUD routes |
| `04-mongoose` | Connecting MongoDB with Mongoose |
| `05-authentication` | Register, JWT, cookies and protected routes |
| `notes` | My own notes on backend concepts |

## Tech
Node.js, Express.js, MongoDB, Mongoose, JWT, cookie-parser

## Running a project
```bash
cd <folder-name>
npm install
npm run dev
```
If the folder has a `.env.example`, copy it to `.env` and fill in your own values.
