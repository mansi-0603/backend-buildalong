# 02 - Express Basics

Core Express concepts: routing, middleware and request data.

## What I learned
- Routes and HTTP methods (GET, POST, PATCH, DELETE)
- Reading data with `req.body`, `req.params` and `req.query`
- Using `express.json()` middleware
- Sending responses with `res.send()` and `res.json()`
- Testing APIs with Postman

## Run
```bash
npm install
node server.js
```
