# 03 - API aur REST API

## API kya hai?
- **A**pplication **P**rogramming **I**nterface
- Rules ka ek set, jiske through **alag-alag applications aapas me communicate** karti hain.

## API ke types

### 1. REST API
- **Re**presentational **S**tate **T**ransfer API
- Jab do applications ko communicate karna hota hai, tab REST API ka standard use hota hai: **HTTP methods** ke through interact karna.

### REST API me use hone wale methods
| Method | Kab use karte hain |
|--------|--------------------|
| `GET` | Server se data **lena (fetch)** ho |
| `POST` | Server par data **send** karna ho |
| `PATCH` | Server par jo data pehle se present hai, use **update** karna ho |
| `DELETE` | Server par present data ko **delete** karna ho |
