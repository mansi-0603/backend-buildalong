2. What should you actually write inside your notes?

I want you to follow a simple structure for EVERY concept.

The 5-point note-taking method
Section	What to write
1. What?	What is this concept?
2. Why?	Why do we need it?
3. How?	How does it work?
4. Example	One small practical code example
5. Interview/Revision	Important questions or things you tend to forget



Har topic ke liye ye 5 parts rakho

Kya hai? (1-2 lines, apne words me)

Kyun chahiye? (iske bina kya problem aati)

Chhota code pattern (sirf 3-6 lines)

Nayi lines ka matlab (sirf wahi jo pehli baar dekhi)

Galti / error jo mujhse hui (ye sabse kaam ka hai)
